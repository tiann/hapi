# Брендовые ассеты HAPI

Канонический источник иконки HAPI, используемый вебом, документацией, сайтом, приложениями
Android и iOS.

## Решения по дизайну

- Лицо, симметричные глаза, улыбка, коралловая палитра и скруглённая рамка робота сохранены.
- Боковые узлы становятся зеркальными портами-уголками: `< HAPI >`.
- Скобки несут два смысла, не затрагивая лицо: контекст разработчика/кода
  и направление передачи локально ↔ удалённо.
- Направленное негативное пространство меняет структуру портов, а не просто
  заменяет круг другим примитивом.
- Вырезы на концах — настоящая прозрачность, они выдерживают монохромное использование.
- Мастер maskable для PWA переиспользует ту же оптическую геометрию в единообразно меньшем
  масштабе, чтобы каждый порт передачи оставался внутри безопасной зоны maskable.
- Поверхности iOS и установленной PWA сохраняют знак робота, используя его существующие
  оптические коррекции для малых размеров: чуть более сильную рамку, глаза, улыбку и
  порты передачи, без бликов на глазах, которые преломляются на iOS 26.
- Пакет Icon Composer для iOS 26 отрисовывает коралловый знак как один плоский,
  не-стеклянный передний план поверх Warm White; он не вводит второй логотип.
- 16 px использует упрощённые сплошные скобки; 32 px и выше сохраняют негативные
  порты-уголки.
- Полотно горизонтального локапа остаётся подтянутым; никакой обработки в виде терминального курсора.

## Палитра

- HAPI Coral: `#F25562`
- Warm White: `#FFF8F8`
- White: `#FFFFFF`
- Ink: `#17181C`

## Исходные SVG

- `svg/hapi-mark.svg` — прозрачный основной брендовый знак.
- `svg/hapi-app-icon.svg` — мастер иконки приложения с полной заливкой.
- `svg/hapi-optical-mark.svg` — прозрачный передний план лаунчера iOS, соответствующий
  оптической геометрии малого размера.
- `svg/hapi-tiny.svg` — упрощённый мастер favicon 16 px.
- `svg/hapi-small.svg` — оптически скорректированный мастер 24–64 px.
- `svg/hapi-maskable.svg` — оптический мастер PWA, масштабированный под безопасную зону.
- `svg/hapi-adaptive-foreground.svg` — мастер адаптивного переднего плана Android.
- `svg/hapi-monochrome.svg` — одноцветный знак.
- `svg/hapi-lockup-horizontal.svg` — подтянутый горизонтальный локап.

## Синхронизация ассетов платформ

```bash
./assets/brand/export.sh
```

Скрипт рендерит во временный каталог, затем обновляет только файлы, используемые
`web/`, `docs/`, `website/`, `android/` и `ios/`. Сгенерированные промежуточные файлы
намеренно не хранятся в репозитории.

Адаптивные, тематические иконки и иконки уведомлений Android остаются нативными ресурсами
VectorDrawable в `android/app/src/main/res/`; при изменении геометрии держите их согласованными с
`svg/hapi-adaptive-foreground.svg`.
